# Local country database

DB-IP IP to Country Lite, licensed under Creative Commons Attribution 4.0:
https://db-ip.com/db/download/ip-to-country-lite
https://creativecommons.org/licenses/by/4.0/

The bundled country.mmdb.gz is an unmodified snapshot. release.json records
its release month and source. The server refreshes the local in-memory database
monthly, checking at most once daily on analytics requests. Downloads contain
no visitor information. All IP lookups are local; raw IPs are never stored in
the analytics table.

The administrator panel links to DB-IP wherever its country results appear.
Lite coverage and accuracy are approximate. Missing or more than 62-day-old
country data is explicitly reported, not substituted with language/timezone.
