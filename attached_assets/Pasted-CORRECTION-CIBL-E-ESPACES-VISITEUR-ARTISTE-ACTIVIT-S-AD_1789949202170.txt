CORRECTION CIBLÉE — ESPACES VISITEUR / ARTISTE / ACTIVITÉS / ADMIN

Le dernier audit a identifié plusieurs écarts fonctionnels.

⚠️ RÈGLE ABSOLUE

NE PAS RECONSTRUIRE INDAMORA PLAY.

La partie suivante est déjà fonctionnelle et doit être conservée :

* Clerk ;
* compte utilisateur ;
* profil INDAMORA séparé du compte Clerk ;
* maximum 2 activités ;
* validation serveur de la limite ;
* bio libre ;
* modification du profil ;
* anciens profils ;
* API existante ;
* RÉPERTOIRE existant ;
* stockage ;
* œuvres ;
* soumissions ;
* modération ;
* paiements ;
* dons ;
* abonnements.

Ne refaire aucune de ces fonctionnalités.

Corriger uniquement les écarts identifiés ci-dessous.

⸻

1. VRAIE SÉPARATION DES ESPACES

Il faut maintenant mettre en place une véritable distinction entre :

🎧 ESPACE VISITEUR / AUDITEUR

🎤 ESPACE ARTISTE / CRÉATEUR / PROFESSIONNEL

🔐 ESPACE ADMINISTRATEUR

Ces espaces ne doivent pas présenter la même interface.

⸻

2. ESPACE VISITEUR / AUDITEUR

Créer le concept d’un espace visiteur/auditeur à partir du système utilisateur existant.

⚠️ Ne pas créer un deuxième système de compte.

Une personne conserve son compte Clerk.

Elle peut avoir un profil INDAMORA de type :

🎧 Auditeur / Visiteur

Cet espace doit permettre notamment :

* gérer son profil personnel ;
* consulter ses informations ;
* découvrir les artistes ;
* consulter le RÉPERTOIRE ;
* écouter les contenus accessibles ;
* gérer ses abonnements ;
* effectuer un don ;
* consulter uniquement ses propres informations.

IMPORTANT

Un visiteur/auditeur ne doit pas voir :

* Espace artiste ;
* Proposer une œuvre ;
* outils de dépôt artiste ;
* modération ;
* gestion d’artistes ;
* gestion des œuvres globales ;
* statistiques globales ;
* dons globaux ;
* revenus ;
* Stripe ;
* outils ADMIN.

⸻

3. ESPACE ARTISTE / CRÉATEUR / PROFESSIONNEL

L’accès à Espace artiste ne doit plus être accordé simplement parce qu’une personne est connectée.

Il doit être conditionné à l’existence d’un profil INDAMORA approprié.

Par exemple :

* 🎤 Artiste ;
* 💃 Danseur / danseuse ;
* 🎚️ Producteur ;
* 🎥 Vidéaste ;
* 🎬 Acteur / réalisateur ;
* 😂 Humoriste ;
* 🎧 Podcasteur ;
* 📱 Créateur de contenu ;
* ⭐ Influenceur ;
* 🎙️ Chantre ;
* ou autre activité professionnelle/créative disponible.

Un simple utilisateur connecté sans profil artiste/professionnel ne doit pas voir automatiquement les outils artistes.

⸻

4. CAS D’UN UTILISATEUR CONNECTÉ SANS ACTIVITÉ

Un utilisateur peut être connecté à Clerk sans encore avoir complété son profil INDAMORA.

Dans ce cas :

ne pas lui afficher automatiquement l’espace artiste.

Lui proposer clairement :

🎨 JE CRÉE MON ESPACE

Puis :

Choisissez votre activité.

Une ou deux activités maximum.

⸻

5. ESPACES ADAPTÉS AUX ACTIVITÉS

Le système actuel utilise un espace artiste générique.

Il faut maintenant commencer à adapter l’espace en fonction des activités choisies.

⚠️ Ne pas inventer de nouvelles fonctionnalités complexes.

Utiliser les fonctionnalités déjà disponibles dans INDAMORA PLAY et simplement adapter :

* le titre de l’espace ;
* les informations affichées ;
* les actions disponibles ;
* les contenus pertinents ;
* les raccourcis.

⸻

Exemple 1

🎤 Artiste + 🎚️ Producteur

Afficher un espace adapté :

Mon espace artiste

avec notamment :

* Mon profil ;
* Mes œuvres ;
* Déposer une œuvre ;
* Mes soumissions ;
* Mes médias ;
* Mes statistiques ;
* Mes notifications.

⸻

Exemple 2

💃 Danseur + 📱 Créateur de contenu

Afficher :

Mon espace créateur

avec les fonctionnalités réellement disponibles correspondant à ce profil.

Ne pas afficher artificiellement une fonction musicale si elle n’est pas nécessaire.

⸻

Exemple 3

🎥 Vidéaste + 📱 Créateur de contenu

Afficher :

Mon espace créateur / média

avec les fonctions existantes pertinentes.

⸻

Exemple 4

📰 Journaliste + 🎬 Média

Afficher un espace professionnel/média adapté.

⸻

6. IMPORTANT — NE PAS CRÉER 15 APPLICATIONS DIFFÉRENTES

Il ne faut pas créer une application différente pour chaque activité.

Il faut conserver un seul INDAMORA PLAY et un seul compte utilisateur.

L’espace est simplement configuré selon les activités du profil.

Architecture souhaitée :

Compte Clerk

↓

Profil INDAMORA

↓

1 ou 2 activités

↓

Espace adapté

⸻

7. ROUTE /PROFIL

Actuellement :

tout utilisateur connecté peut accéder à /profil et voit directement le parcours de création d’un profil artiste.

Corriger ce comportement.

Le profil doit être adapté à la situation :

Aucun profil INDAMORA

Afficher :

Créer mon espace

Profil visiteur/auditeur

Afficher :

Mon espace visiteur

Profil artiste/créateur/professionnel

Afficher :

Mon espace professionnel adapté à mes activités

ADMIN

Afficher l’accès au :

Centre de pilotage ADMIN

selon les permissions existantes.

⸻

8. ROUTE /ESPACE-ARTISTE

Actuellement, la route vérifie principalement que l’utilisateur est connecté.

Corriger cela.

L’accès doit vérifier côté serveur :

1. utilisateur authentifié ;
2. profil INDAMORA existant ;
3. activité autorisée ;
4. permissions correspondantes.

Un simple visiteur connecté ne doit pas pouvoir utiliser l’espace artiste.

⸻

9. LIEN « PROPOSER UNE ŒUVRE »

Actuellement tout utilisateur connecté peut voir ce lien.

Corriger.

Le lien doit être visible uniquement pour les profils disposant d’une activité permettant réellement de déposer une œuvre.

Si un visiteur souhaite devenir artiste/créateur :

lui proposer :

Créer mon espace professionnel

et l’orienter vers JE CRÉE.

⸻

10. PARCOURS /SUBMIT

Le parcours :

/submit → Ajouter mon profil au répertoire

permet actuellement de créer potentiellement un profil sans activité.

Corriger ce parcours.

Il doit utiliser le même système de profil et d’activités.

Avant de créer le profil :

activité 1 obligatoire

activité 2 facultative

maximum 2

Impossible de créer un profil public sans activité structurée si le profil est destiné au RÉPERTOIRE.

Ne pas créer un deuxième formulaire parallèle.

Réutiliser le système existant.

⸻

11. RÉPERTOIRE

Le RÉPERTOIRE reste le centre du système.

Conserver :

* recherche ;
* filtres ;
* catégories ;
* sous-catégories ;
* profils ;
* œuvres.

Ajouter uniquement si nécessaire l’utilisation des activités déjà enregistrées.

Exemple :

Artistes

Danseurs

Producteurs

Vidéastes

Créateurs de contenu

etc.

Ne pas reconstruire le RÉPERTOIRE.

⸻

13. JOURNAL ADMIN — À COMPLÉTER

L’audit indique qu’il existe une activité récente mais pas encore de véritable journal ADMIN complet.

Mettre en place uniquement le nécessaire pour enregistrer les actions ADMIN importantes :

* validation ;
* rejet ;
* publication ;
* modification ;
* dépublication ;
* suppression ;
* gestion d’un profil ;
* gestion d’une œuvre ;
* gestion d’un média.

Chaque entrée doit idéalement contenir :

* administrateur ;
* action ;
* élément concerné ;
* date/heure ;
* résultat.

Le journal doit être accessible uniquement aux ADMIN autorisés.

Ne pas créer de journal fictif.

RÈGLE FINALE

UN SEUL COMPTE.

UN SEUL INDAMORA PLAY.

Mais :

ESPACE VISITEUR ≠ ESPACE ARTISTE/CRÉATEUR ≠ ESPACE ADMINISTRATEUR.

Et :

ARTISTE ≠ DANSEUR ≠ VIDÉASTE ≠ PRODUCTEUR ≠ JOURNALISTE, même si plusieurs activités peuvent appartenir au même compte.

Une personne peut choisir maximum 2 activités, et son espace doit tenir compte de ces activités.

Le système doit rester simple, cohérent et évolutif.

Ne pas reconstruire INDAMORA PLAY.

Corriger uniquement les écarts identifiés.

Tester réellement avant de déclarer terminé.
