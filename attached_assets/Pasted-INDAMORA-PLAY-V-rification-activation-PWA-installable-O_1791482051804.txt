PWA — VÉRIFICATIONS OBLIGATOIRES

Vérifie notamment :

1. Web App Manifest

Il doit exister un manifest valide contenant au minimum :

* name : INDAMORA PLAY
* short_name : INDAMORA PLAY
* start_url approprié
* display : standalone ou équivalent adapté
* background_color cohérent avec le site
* theme_color cohérent avec le site
* icône adaptée au format PWA

Utiliser le logo/les assets officiels déjà présents.

⚠️ NE PAS redessiner le logo.

Si des icônes PWA existent déjà et sont correctes, les réutiliser.

⸻

2. Service Worker

Vérifier si un service worker existe déjà.

S’il existe et fonctionne :

* ne pas le remplacer inutilement.

S’il manque et qu’il est réellement nécessaire pour l’installation/le fonctionnement PWA :

* ajouter la solution minimale ;
* éviter une stratégie de cache agressive pouvant servir d’anciennes versions du site ;
* ne pas mettre en cache des données sensibles ou des réponses API dynamiques.

La PWA doit pouvoir continuer à recevoir les nouvelles versions du site normalement.

⸻

3. HTML / META

Vérifier les éléments nécessaires à l’installation PWA :

* lien vers le manifest ;
* theme-color ;
* viewport mobile ;
* métadonnées nécessaires selon la plateforme ;
* configuration iOS/iPadOS permettant l’utilisation en mode standalone lorsque supportée.

Ne pas supprimer ni remplacer les métadonnées existantes utiles au référencement.

⸻

4. HTTPS

Vérifier que la PWA est servie en HTTPS.

Ne pas modifier le domaine de production.

⸻

5. Installation mobile

Vérifier la compatibilité avec :

* Android + Chrome ;
* iPhone/iPad + Safari.

Le résultat attendu est :

Android :
Navigateur → menu → Ajouter à l’écran d’accueil / Installer l’application.

iPhone/iPad :
Safari → Partager → Sur l’écran d’accueil.

Il n’est PAS nécessaire de publier sur Google Play ou App Store.

Coût attendu : 0 €.
