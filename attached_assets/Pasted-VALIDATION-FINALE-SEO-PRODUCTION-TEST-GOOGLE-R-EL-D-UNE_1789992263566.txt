VALIDATION FINALE SEO PRODUCTION + TEST GOOGLE RÉEL D’UNE PAGE ARTISTE

⚠️ RÈGLE ABSOLUE

NE RECONSTRUIS PAS INDAMORA PLAY.

Ne refais pas le site, ne change pas son architecture et ne remplace aucune fonctionnalité qui fonctionne déjà.

La production actuelle est la référence fonctionnelle.

Le dépôt GitHub peut être différent de la version actuellement publiée : ne considère donc pas une différence avec GitHub comme un problème à corriger automatiquement.

Objectif : publier/valider les améliorations SEO déjà préparées et vérifier leur fonctionnement réel sur https://indamoraplay.com.

Après chaque éventuelle correction :

TEST → VÉRIFICATION → CORRECTION → RETEST

Si tout fonctionne déjà, NE MODIFIE RIEN.

⸻

1. PUBLIER LES MODIFICATIONS SEO EXISTANTES

Si les modifications SEO déjà préparées sont correctes et n’ont pas encore été publiées :

* publier la version actuelle ;
* ne modifier que ce qui est nécessaire à la publication ;
* ne pas refaire le travail SEO déjà réalisé.

Après publication, travailler uniquement avec :

https://indamoraplay.com

⸻

2. VÉRIFIER LE SITEMAP RÉEL EN PRODUCTION

Ouvrir réellement :

https://indamoraplay.com/sitemap.xml

Vérifier que le sitemap :

* est accessible publiquement ;
* répond correctement ;
* contient la page d’accueil ;
* contient RÉPERTOIRE ;
* contient les pages publiques d’artistes ;
* contient les pages publiques d’œuvres lorsque leur structure existe ;
* n’inclut pas de pages privées ;
* n’inclut pas les pages administrateur ;
* n’inclut pas les pages nécessitant une connexion ;
* n’inclut pas les profils en attente, rejetés ou non publiés ;
* n’inclut pas d’URL invalides.

Ne crée aucune fausse URL pour remplir le sitemap.

⸻

3. VÉRIFIER ROBOTS.TXT EN PRODUCTION

Ouvrir :

https://indamoraplay.com/robots.txt

Vérifier qu’il n’empêche pas inutilement Google d’explorer les pages publiques.

Les espaces privés, administratifs et contenus qui ne doivent pas être indexés doivent rester protégés selon leur fonctionnement prévu.

⸻

4. VÉRIFIER LA CANONICAL

Sur les principales pages publiques, vérifier que la canonical utilise bien le domaine officiel :

https://indamoraplay.com

Vérifier notamment :

* Accueil ;
* RÉPERTOIRE ;
* vraie page artiste ;
* vraie page œuvre publique, lorsqu’elle existe.

Éviter toute canonical accidentelle vers :

* le domaine Replit ;
* une URL de preview ;
* une URL interne ;
* une URL privée.

⸻

5. CHOISIR UN VRAI ARTISTE EXISTANT

C’est une étape essentielle.

Utilise un artiste réel déjà présent dans les données de production de INDAMORA PLAY, avec un profil public réellement publié.

Ne crée :

* aucun faux artiste ;
* aucun faux compte ;
* aucune fausse œuvre ;
* aucune fausse écoute ;
* aucune fausse statistique.

Indique dans le rapport :

Artiste réellement testé : [nom]

⸻

6. TESTER LA VRAIE PAGE ARTISTE

Ouvrir la véritable page publique de cet artiste sur :

https://indamoraplay.com

Vérifier réellement :

* accès sans connexion ;
* nom de l’artiste ;
* pseudo/nom d’artiste ;
* catégorie ou activité ;
* présentation/bio ;
* localisation/pays lorsque ces informations sont publiques ;
* image/avatar si disponible ;
* œuvres publiques ;
* liens vers les œuvres ;
* liens internes ;
* fonctionnement mobile ;
* absence de redirection vers connexion ;
* absence de noindex ;
* canonical correcte ;
* contenu essentiel réellement présent dans la page rendue ;
* URL propre et stable.

Le profil doit être une vraie page publique exploitable par un visiteur et par les moteurs de recherche.

⸻

7. TESTER LE PARCOURS RÉPERTOIRE → ARTISTE

Vérifier également :

https://indamoraplay.com → RÉPERTOIRE → artiste réel → profil → œuvres publiques

Puis :

profil artiste → œuvre publique → lecture/découverte

RÉPERTOIRE doit rester le cœur de cet écosystème.

Ne crée pas un deuxième système parallèle pour les artistes.

⸻

Avec le nom réel de l’artiste sélectionné, effectuer au minimum ces recherches :

”[Nom réel de l’artiste] INDAMORA PLAY”

Recherche 3

”[Nom réel de l’artiste] Centrafrique”

Recherche 4

”[Nom réel de l’artiste] Bangui”

Puis, si cela correspond réellement à son activité :

Recherche 5

Recherche 6

”[Nom réel de l’artiste] artiste centrafricain”

Ne force pas les mots-clés.

Utilise uniquement les formulations pertinentes pour cet artiste réel.

9. DOCUMENTATION DU RÉSULTAT GOOGLE

Pour chaque recherche, indique précisément ce qui est réellement observé.

Par exemple :

* page INDAMORA PLAY trouvée ;
* page INDAMORA PLAY non trouvée ;
* autre résultat trouvé ;
* artiste connu de Google mais page INDAMORA PLAY non affichée ;
* aucun résultat pertinent.

Ne fabrique jamais un résultat.

Ne dis pas qu’une page est indexée simplement parce qu’elle est présente dans le sitemap.

Une demande d’indexation n’est pas une garantie d’indexation ou d’apparition dans les résultats.
