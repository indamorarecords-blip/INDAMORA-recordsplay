7. STRIPE

Intégrer Stripe Checkout pour les paiements.

IMPORTANT :

Utiliser l’intégration Stripe moderne recommandée.

Pour les paiements uniques de produits :
Checkout Sessions API.

Ne pas utiliser :

* Charges API ;
* ancienne intégration Card Element ;
* système de paiement développé maison ;
* stockage de données de carte bancaire dans notre application.

Utiliser Stripe Checkout afin que les informations de paiement soient traitées par Stripe.

Ne pas transmettre ni stocker de numéro de carte bancaire dans l’application.

Ne pas utiliser payment_method_types en dur : laisser Stripe gérer les moyens de paiement dynamiques disponibles.

9. WEBHOOK STRIPE

Prévoir un endpoint webhook sécurisé pour Stripe.

Le webhook doit :

* vérifier la signature Stripe ;
* traiter les événements de paiement pertinents ;
* confirmer qu’un paiement est réellement payé avant de considérer une commande comme payée ;
* éviter les doubles traitements ;
* permettre plus tard de gérer proprement les commandes et la préparation des livraisons.

Prévoir notamment les événements Checkout pertinents, dont :

checkout.session.completed

et les événements de paiement asynchrone lorsque nécessaire.

Ne pas considérer simplement la page « paiement réussi » comme preuve suffisante d’un paiement.
