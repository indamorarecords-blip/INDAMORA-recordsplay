NOUVELLE TÂCHE — TRANSFORMER L’ANNUAIRE EN RÉPERTOIRE COMMUNAUTAIRE INDAMORA PLAY

OBJECTIF

L’annuaire d’INDAMORA PLAY ne doit pas être limité à un simple annuaire d’artistes.

Il doit évoluer vers un véritable RÉPERTOIRE COMMUNAUTAIRE INDAMORA PLAY, réunissant les artistes, créateurs, professionnels, acteurs culturels et spirituels, médias et partenaires.

L’ambition est de contribuer à réunir la communauté musicale et culturelle d’Afrique centrale et, progressivement, d’Afrique et du monde.

L’objectif devient :

Découvrir les talents, créateurs, professionnels, acteurs culturels, médias et partenaires qui font vivre l’écosystème INDAMORA PLAY.

⸻

⚠️ RÈGLE ABSOLUE : CONSERVER L’EXISTANT

NE PAS SUPPRIMER, REFAIRE OU CASSER CE QUI FONCTIONNE DÉJÀ.

Avant toute modification :

1. inspecter l’annuaire actuel ;
2. inspecter les profils existants ;
3. inspecter les tables et relations ;
4. inspecter les routes ;
5. inspecter les composants ;
6. inspecter les permissions ;
7. inspecter les fonctionnalités déjà opérationnelles ;
8. identifier ce qui peut être simplement étendu.

Si une fonctionnalité fonctionne déjà correctement :

LA CONSERVER.

Ne pas reconstruire inutilement.

Ne pas créer de doublons :

* pas deux systèmes de profils ;
* pas deux systèmes de catégories ;
* pas deux annuaires ;
* pas deux systèmes de validation ;
* pas deux systèmes de partenaires.

Réutiliser et étendre l’architecture existante autant que possible.

⸻

1. NE PAS MULTIPLIER LES MENUS

L’interface doit rester simple, élégante et mobile-first.

Ne pas créer un menu principal pour chaque catégorie.

❌ Pas de menu principal Gospel
❌ Pas de menu principal DJ
❌ Pas de menu principal Vidéastes
❌ Pas de menu principal Podcasts
❌ Pas de menu principal Influenceurs
❌ Pas de menu principal Partenaires
❌ Pas de menu principal Presse

📖 RÉPERTOIRE

Le RÉPERTOIRE devient le point d’entrée central de tous les profils professionnels et communautaires.

Exemple :

ACCUEIL | MUSIQUE | VIDÉOS | RÉPERTOIRE | RECHERCHE | PREMIUM | SOUTENIR

14. COMPTES ET RÔLES

Les catégories professionnelles ne doivent JAMAIS devenir des rôles de sécurité.

Exemple :

Un membre peut avoir :

Catégorie : DJ

mais son rôle technique reste celui prévu par le système existant :

USER / ARTIST / etc.

Même principe pour :

* chanteur ;
* humoriste ;
* vidéaste ;
* podcasteur ;
* journaliste ;
* partenaire ;
* créateur de contenu ;
* etc.

IMPORTANT

Catégorie professionnelle = organisation du RÉPERTOIRE.

Rôle technique = permissions et sécurité.

Ne jamais mélanger les deux.

⸻

15. SÉCURITÉ

Respecter toutes les protections déjà présentes dans INDAMORA PLAY.

Les informations publiques peuvent apparaître dans le RÉPERTOIRE.

Les informations privées doivent rester privées.

Ne jamais exposer :

* mots de passe ;
* tokens ;
* clés secrètes ;
* données financières privées ;
* données personnelles non destinées au public ;
* informations internes de modération.

Les permissions doivent être vérifiées côté serveur.

Un bouton caché n’est pas une sécurité.

24. RÈGLE FINALE

NE PAS CHERCHER À REFAIRE INDAMORA PLAY.

Le projet existe déjà.

Faire évoluer proprement l’existant pour qu’INDAMORA PLAY devienne progressivement une plateforme réunissant :

musique + artistes + créateurs + professionnels + médias + partenaires + communauté.

Toute fonctionnalité déjà opérationnelle doit être conservée.

Toute fonctionnalité incomplète doit être finalisée.

Toute fonctionnalité cassée doit être corrigée uniquement si nécessaire.

Ne pas multiplier les menus.

RÉPERTOIRE doit être le point central de cet écosystème.

Après chaque modification importante :

TESTER → VÉRIFIER → CORRIGER → RETESTER.

Ne considérer cette tâche comme terminée que lorsque le RÉPERTOIRE fonctionne réellement avec les données existantes, les profils, les catégories, les filtres, la recherche, les permissions et l’affichage public.
