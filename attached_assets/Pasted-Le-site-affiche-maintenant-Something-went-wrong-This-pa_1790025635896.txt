⚠️ DIAGNOSTIC UNIQUEMENT AU DÉPART.

NE RECONSTRUIS PAS INDAMORA PLAY.
NE SUPPRIME RIEN.
NE CHANGE PAS LE DESIGN.
NE REMPLACE PAS LES FONCTIONNALITÉS EXISTANTES.

Le site officiel reste :

https://indamoraplay.com/

1. IDENTIFIER L’ERREUR EXACTE

Détermine précisément :

* quelle page ou quel composant provoque l’erreur ;
* quelle action déclenche l’erreur ;
* l’erreur JavaScript exacte ;
* la stack trace ;
* l’erreur réseau éventuelle ;
* l’endpoint API concerné ;
* si l’erreur vient du manifest PWA ;
* si elle vient du service worker ;
* si elle vient du cache ;
* si elle vient d’une modification récente liée à la PWA.

Vérifie également les logs serveur et console navigateur.

2. COMPARER AVANT/APRÈS

Identifie uniquement les modifications effectuées juste avant l’apparition de cette erreur.

Ne touche pas aux parties qui n’ont aucun rapport avec l’erreur.

3. TESTER LE SITE NORMAL

Vérifie :

* Accueil ;
* Explorer ;
* RÉPERTOIRE ;
* recherche ;
* profil artiste ;
* connexion ;
* lecture audio ;
* lecture vidéo ;
* Premium ;
* dons ;
* espace artiste ;
* administration si autorisé.

Détermine exactement quelle partie fonctionne et quelle partie est cassée.

4. PWA

Teste séparément :

* chargement normal du site ;
* manifest ;
* service worker ;
* installation PWA ;
* navigation après installation.

Si le service worker ou le cache provoque l’erreur, corrige uniquement cette partie.

⚠️ Ne mets jamais en cache des données privées, des sessions ou des informations de paiement.

5. CORRECTION MINIMALE

Une fois la cause identifiée :

* corrige uniquement la cause ;
* conserve tout le reste ;
* ne refais pas l’architecture ;
* ne change pas le backend inutilement ;
* ne touche pas à Stripe ;
* ne touche pas aux dons ;
* ne touche pas au RÉPERTOIRE sauf si l’erreur vient réellement de celui-ci.

6. RETEST OBLIGATOIRE

Après correction :

TEST → VÉRIFICATION → CORRECTION SI NÉCESSAIRE → RETEST

Teste à nouveau :

* desktop ;
* mobile ;
* PWA ;
* navigation ;
* authentification ;
* RÉPERTOIRE ;
* profils ;
* audio/vidéo ;
* Premium ;
* dons.

7. RAPPORT FINAL

Donne-moi :

1. la cause exacte de l’erreur ;
2. le fichier concerné ;
3. la correction effectuée ;
4. les tests réalisés ;
5. ce qui fonctionne maintenant ;
6. ce qui reste éventuellement à corriger.

Si l’erreur ne peut pas être reproduite, ne modifie rien au hasard.

Le but est uniquement de réparer l’erreur actuelle avec le minimum absolu de modifications.

INDAMORA PLAY doit rester intacte.
